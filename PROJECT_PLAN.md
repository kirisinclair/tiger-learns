# План проекта «Tiger learns!» — приложение для изучения испанского

Дата создания: 2026-08-10. Статус: **решения приняты, идёт разработка.**

---

## 1. Что делаем

Приложение для русскоязычных, изучающих испанский (латиноамериканский вариант).
Основа — бесконечная тренировка по методу интервального повторения (SRS).
Цель по объёму: **полностью закрыть потребности учащегося уровня A2**
(то есть A1 + A2), плюс частотный словарь испанского языка.

Ключевые свойства:
- Windows и Android, один код.
- Полностью офлайн, прогресс на устройстве.
- Дизайн по скриншотам: светлый минимализм, белые «пилюли», оранжевый акцент.

## 3. Диалект: Латинская Америка

Пользователь выбрал латиноамериканский вариант. Практические следствия:

1. **Нет `vosotros`.** В Латинской Америке множественное «вы» — это `ustedes`
   (форма 3 л. мн. ч.). На исходном скриншоте среди вариантов есть `habláis` —
   это форма Испании.
   **Решение:** в настройках переключатель `Латинская Америка / Испания`,
   **по умолчанию Латинская Америка**. При LatAm формы `vosotros` не спрашиваются,
   но могут показываться как неправильные варианты-отвлекатели.
2. **Прошедшее время.** В Латинской Америке для завершённого прошлого почти
   всегда используется **Pretérito Indefinido** (`hablé`), а не Pretérito
   Perfecto (`he hablado`). Раздел «прошедшее время» строим на Indefinido.
3. **Лексика.** Где расходится — берём латиноамериканский вариант, а испанский
   даём пометкой: `carro` (Исп.: `coche`), `computadora` (Исп.: `ordenador`),
   `celular` (Исп.: `móvil`), `jugo` (Исп.: `zumo`), `papa` (Исп.: `patata`).

## 3а. Правила для придуманного контента

**Обращение на «ты».** Приложение обращается к пользователю на «ты»: «Обрати
внимание», «Ты его вспоминаешь», «перезапусти браузер». Никаких «вы находитесь»
и «нажмите».

Исключение, и оно важное: «Вы» и «вы» внутри **переводов** остаются как есть.
Это не обращение к пользователю, а перевод испанских `usted`, `ustedes` и
`vosotros`, и там регистр несёт грамматический смысл — «Вы работаете по
воскресеньям?» обращено к продавцу, а не к учащемуся.


**Без семейных сюжетов.** В мнемониках, примерах к правилам и тренировочных
фразах не должно быть семьи и особенно матерей. Правило распространяется на всё
сочинённое; словарные статьи (`madre`, `padre` в частотном списке и в
тематическом разделе A2) остаются — это лексика, а не сюжет.

**Чем заменять:** необычное и неожиданное — животные, космос, история,
природа. Бытовые предметы тоже подходят: кофе, ключи, зонт, автобус.

Причина не только вкусовая: «позвони маме» — самый затасканный пример в
учебниках, и именно поэтому он не запоминается.


**Только позитивные формулировки. Никакой позиции жертвы и дефицита.**

Обсуждено 2026-08-30, наравне с запретом на семью. Под запретом всё, где у
меня, у нас или у них чего-то нет и "бедные мы несчастные": «я не богат», «я
не миллионер», «у меня нет удачи», «я остаюсь без денег», «я не могу ничего
понять». Вместо этого утверждаем: «я богатый», «я миллионер», «у меня много
удачи», «у нас много ресурсов», «у нас есть всё необходимое», «я способен на
многое».

**Почему.** Эти фразы читаются сотни раз подряд — это не нейтральный
материал, а то, что откладывается. Учебная фраза не обязана быть про
нехватку, чтобы научить отрицанию.

**Что при этом можно.** Само отрицание — обязательная грамматика, и оно
остаётся. Отрицать нужно то, что не про недостаток: «я не работаю без
отдыха», «я не даю советов без спроса», «я не должен ничего никому», «у меня
нет страха темноты». Отрицание границы или страха — это сила, а не жалоба.

## 4. Структура контента

Три независимых слоя данных, все в JSON, отдельно от кода:

### 4.1. Лексикон (`content/lexicon/*.json`)
Единая база слов. Одно слово — одна запись, и она может одновременно быть
и в частотном списке, и в тематическом словаре A2. Дублирования нет.

```jsonc
{
  "id": "es.hablar",
  "es": "hablar",
  "ru": ["говорить", "разговаривать"],
  "pos": "verb",
  "rank": 118,          // место в частотном списке; null — если вне топа
  "cefr": "A1",         // A1 | A2 | B1
  "topics": ["communication"],
  "regional": { "es_ES": "hablar" },  // если вариант Испании отличается
  "example": { "es": "Hablo español.", "ru": "Я говорю по-испански." }
}
```

Так решается вопрос «частотный словарь и словарь A2 пересекаются»:
`rank` и `cefr` — **два независимых поля**, слово попадает в оба среза
автоматически, а разделы приложения — это просто фильтры по этим полям.

### 4.2. Глаголы (`content/verbs/*.json`)
Инфинитив + тип спряжения + таблица неправильных форм. Правильные формы
приложение генерирует по правилам, руками хранятся только исключения.

### 4.3. Разделы и правила (`content/decks.json`, `content/rules/*.md`)
Раздел = название + фильтр по лексикону или явный список id + тип упражнений.

### 4.4. Источники частотного списка
- [Wiktionary: Frequency lists / Spanish](https://en.wiktionary.org/wiki/Wiktionary:Frequency_lists/Spanish) — открытый список по субтитрам (смешанный корпус, много разговорной речи)
- [Most common words in Spanish (Wikipedia)](https://en.wikipedia.org/wiki/Most_common_words_in_Spanish) — обзор корпусов, в т.ч. CREA (RAE, все испаноязычные страны)
- Mark Davies, *A Frequency Dictionary of Spanish* — корпус 20 млн слов, поровну Испания и Латинская Америка (справочно, книга под копирайтом, список не копируем)
- [Plan Curricular del Instituto Cervantes, инвентари A1-A2](https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/niveles/09_nociones_especificas_inventario_a1-a2.htm) — официальный перечень тем и понятий для A1/A2, по нему строим тематический словарь

Частотный список составляется по этим ориентирам, чистится от служебного мусора
и снабжается русскими переводами вручную (переводов в открытых списках нет).

## 7. Интервальное повторение

Алгоритм **SM-2** (как в Anki):
- у каждой карточки: интервал, коэффициент лёгкости, дата следующего показа;
- ошибся → карточка возвращается в текущую сессию и интервал сбрасывается;
- ответил → интервал растёт: 1 день → 3 дня → неделя → 2 недели → месяц → …;
- карточки никогда не выбывают окончательно — отсюда «бесконечное повторение»;
- когда на сегодня повторять нечего, добираются новые карточки раздела.

Тип упражнения подбирается по «зрелости» карточки: новая → выбор из 6,
знакомая → перевод, зрелая → ввод с клавиатуры и аудирование.

## 7а. Сколько глаголов спрягается на каждом уровне

Примерно пятьдесят самых частотных глаголов покрывают около 80% всех
употреблений глаголов в повседневной речи; дальше отдача на карточку резко
падает. Поэтому спряжения разделены:

- **A1 — 45 глаголов:** 27 правильных (11 на `-ar`, 9 на `-er`, 7 на `-ir`)
  и 18 неправильных. Неправильных много не потому, что так сложнее, а потому,
  что самые частотные глаголы испанского как раз неправильные:
  ser, estar, ir, tener, hacer, poder, querer, decir, ver, dar, saber, venir,
  poner, salir, conocer, pensar, volver, dormir.
- **A2 — остальные 65 глаголов**, плюс все времена сверх настоящего и
  прошедшего.

Значения глаголов при этом учатся на A1 у всех 110 — словарные разделы не
урезаны, урезаны только спряжения.

Списки: `A1_REGULAR_VERB_IDS`, `A1_IRREGULAR_VERB_IDS` в `src/content/verbs.ts`.
Перенести глагол между уровнями — переставить строку из одного списка в другой.

### Как собирается русская подсказка

Схема: **подлежащее + отрицание + глагол + хвост**, и каждую часть можно
подменить, потому что русский устроен иначе, чем испанский.

- Глагол берётся из перевода испанского глагола, но заготовка фразы может
  назвать другой через поле `ruVerb` — русский выбирает глагол под дополнение:
  «делать уроки», но «задавать вопросы», «готовить ужин», «собирать чемодан».
  Формы этих глаголов лежат в `content/ruVerbs.ts` списком, а не выводятся по
  правилу: это как раз те случаи, где правило ошибается.
- Подлежащее и отрицание подменяет `tener`: «У меня есть собака», «У меня нет
  времени». В прошедшем связка согласуется с предметом, поэтому она в хвосте
  (`ruTailPast`: «была собака»).

**Правило для новых заготовок:** написать фразу по-русски целиком и посмотреть,
какой глагол в ней стоит. Если не тот, что в словарной статье, — указать
`ruVerb`. Хвост пишется в том падеже, которого требует этот глагол, и в
отрицательных фразах — в родительном («не задаю вопросов»).

## 8в. Когда понадобится: аккаунты, синхронизация, Google Play

Обсуждено 2026-09-12. Пока не строим — не раньше, чем появятся люди, которым
нужен прогресс на двух устройствах. План держим готовым.

**Что уже есть.** Экспорт/импорт файла — это синхронизация с человеком вместо
сервера: один JSON (карточки, статистика, настройки, история) и слияние, которое

**Бэкенд:** Supabase (Postgres + вход + правила доступа), бесплатного тарифа
хватит надолго. Сайт остаётся на GitHub Pages, браузер ходит в Supabase напрямую.

**Данные:** одна строка на человека — `user_id`, `payload` (тот JSON),
`updated_at`; правило доступа на уровне базы: только своя строка.

**Вход:** по почте без пароля (магическая ссылка) или через Google.

**Синхронизация — локальное хранилище главное.** Без входа приложение работает
как сейчас. Вошёл — при старте тянет и сливает, после сессии и при уходе со
вкладки отправляет. Первый вход вливает накопленное без аккаунта, ничего не
теряя.

**Гигиена:** удаление аккаунта и данных (в приложении и по внешней ссылке —
требование Google Play), заметка о хранении, выбор региона базы.

**Оценка:** 3–5 дней. От пользователя: аккаунт Supabase, проект, регион, адрес
проекта и публичный ключ; для входа через Google — регистрация приложения в
Google Cloud.

**APK и Google Play поверх этого.** Код тот же, оболочка Tauri. Добавляется:
глубокая ссылка для возврата из письма/Google в приложение (день); аккаунт
разработчика ($25), политика конфиденциальности по ссылке, анкета безопасности
данных, иконка и скриншоты (день + проверка Google); ключ подписи релиза,
который нельзя терять. Первая сборка Android — 2–3 дня, ~6 ГБ инструментов.
Обновления APK идут версиями через проверку, сайт — через полминуты после
коммита.

**Порядок:** синхронизация → APK мимо магазина на своём телефоне → Play.
